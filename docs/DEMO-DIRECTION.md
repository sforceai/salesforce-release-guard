# Demo direction: one delete, a caller left behind

## Central story

A proposed deletion still has source references in the destination, including a caller outside release scope. The plugin makes those references inspectable before a human approves anything. The source graph is not a prediction of runtime failure.

The film should feel like a consultant showing the one detail that matters. No AI avatar, generic product introduction, generated code rain, stock hacker imagery, invented live status or dramatic claim of a prevented breach.

## Visual identity

- Warm paper canvas, dark green ink, restrained lime emphasis and a red branch endpoint.
- Large editorial serif headlines paired with readable system UI text.
- One prominent evidence-backed review item rather than a wall of tiles.
- A dark green source map as the technical evidence surface.
- Original inline SVG mark; built-in fonts; no external assets or paid dependencies.

The review, comparison and access reports share this identity. Existing controls, data, escaping, uncertainty and limits remain intact. The removal card's reference count comes from the generated report, not a presentation-only counter.

The first Hermes scene must be captured only after a model-driven end-to-end run works. The hook scene must be labeled as a recorded host test if it uses the deterministic verification receipt. Do not stage fake chat bubbles, fabricated tool results or instant results while real work is still running. Preparation and rendering waits can be edited out, with cuts visible.

## Narration draft

Deleting a class is easy. Finding who still needs it is the hard part.

This is Salesforce Guard, running inside Hermes.

Here is a proposed release and a destination snapshot. One class is explicitly marked for deletion.

Open its impact. The destination has two source references. One caller sits outside this release.

That is a question worth answering before deployment.

Now, a separate user-access check. The public field is readable. The sensitive field and edits stay denied.

The reviewer has limits too. In the recorded Hermes host test, an unrelated tool is blocked before execution.

These are review signals and scoped checks, not a promise that the whole org is secure. Open the source evidence. See what was not assessed.

Salesforce Guard. Review the change. Follow the consequences.

## Sound and pacing

Prefer the entrant's natural voice: calm, direct, lightly conversational, with a pause after the opening question. Keep breaths and small human variations; avoid the continuous, emphatic cadence of a synthetic sales read. Target roughly 140–150 words per minute, then measure the actual take.

If no human recording is available, a caption-led edit with real keyboard/click sounds is a cleaner free alternative to a conspicuous robotic voice. Use only self-recorded sounds; no unlicensed music. There is no need for a soundtrack under source evidence.

Use deliberate cuts, one zoom to the retained caller, captions of roughly six words, and a legible pointer. No spinning transitions or rapid scrolling. All displayed source, users and data must be fictional. Do not film OAuth, org browser chrome, private paths or raw live receipts.

This is a production plan and script, not a completed recording. No MP4, audio or external post was generated in this stage.
